## Project Overview

This project is a coursework workspace for practicing HTML forms, PHP processing, form submissions, session handling, and server-side web programming.

The project is hosted on the Georgia State University CODD instructional server. It includes PHP pages, HTML forms, supporting CSS, and coursework extension pages.

All example submissions should use fictional information only. This project is for classroom practice and is not a real payment or transaction service.
